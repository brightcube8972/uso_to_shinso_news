# uso_to_shinso_news

アプリ「嘘と真相 - 推理ノベル」のトップに出すお知らせ。
GitHub Pages で https://brightcube8972.github.io/uso_to_shinso_news/news.json として公開し、アプリが起動時に読みに来る。

news.json を編集して push すれば、アプリの更新なしでお知らせが変わる（反映まで数分）。

- date: "2026.10.12" の形
- tag: 新作 / お知らせ / 予告（新作だけ赤い枠）
- story: その作品を開くお知らせなら作品ID（例 shiromine_sa）。なければ省略
